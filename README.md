# Anime Zone 🎥

Anime Zone is a modern anime streaming platform where users can browse and watch a wide variety of anime series from recent years and all-time favorites.

## 🚀 Features
- Clean, responsive user interface
- Organized anime catalog (2020-present & all-time top titles)
- Search and filter anime easily
- Watch anime directly in-browser
- Fully client-side (HTML, CSS, JS)

## 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla)

## 📁 Project Structure

```
index.html       - Main HTML file
style.css        - CSS styling
app.js           - JavaScript functionality
.gitignore       - Git ignore rules
LICENSE          - Project license
README.md        - Project overview
```

## 💡 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/genesisvoid/Anime-zone.git
   ```

2. Open `index.html` in any modern browser.
